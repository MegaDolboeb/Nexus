# Сборка Nexus в .exe

Запустить `build.bat` (или `.venv\Scripts\python.exe -m PyInstaller packaging\nexus.spec --noconfirm --distpath packaging\dist --workpath packaging\build` вручную). Результат — папка `packaging\dist\Nexus\`.

## Важно

- **Это папка, не один файл.** Nexus хранит свои данные (`data/`, `personal/`, `logs/`, `backups/`) рядом с собой же (`nexus/config.py: ROOT` — путь к себе). Раздавать и переносить нужно всю папку `Nexus\` целиком, не один `Nexus.exe` — иначе некуда будет сохранять.
- **Ollama нужна отдельно.** Nexus использует свой собственный движок Ollama (порт 11436, своя папка моделей) — саму программу `ollama.exe` в .exe пока не зашиваем, её нужно поставить отдельно (ollama.com). Сами модели можно скачать прямо из панели (Настройки → Модели → «Скачать»).
- **Windows SmartScreen будет ругаться** — .exe не подписан (платная подпись кода стоит денег и требует отдельной процедуры). Это ожидаемо, не баг.
- **Замок целостности (раздел 10) в .exe не проверяется** — исходники запакованы внутрь, сверять их по файлам негде. Это нормально: тамп-эвиденс имеет смысл только при запуске из исходников.
- Первый запуск создаст `personal/`, `data/`, `logs/`, `secrets/` рядом с `Nexus.exe` — если их нет, возьмутся примеры из `config/*.example.json`.
