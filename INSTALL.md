# Установка Nexus

## Вариант 1 — просто запустить (если тебе дали готовую папку)

1. Скачай и распакуй папку `Nexus` целиком (не вынимай `Nexus.exe` из неё отдельно — движок,
   на котором работает Nexus, лежит рядом, в папке `ollama`).
2. Дважды кликни `Nexus.exe`. Ставить что-то ещё не нужно.
3. Откроется окно программы. Первый раз зайди в **Настройки → Модели** и скачай модель
   (например, напиши `qwen3.5:9b` и нажми «Скачать» — подождать придётся, модель весит несколько
   гигабайт).
4. Всё остальное — темы, источники, язык — уже настроено по умолчанию, но можно менять в
   **Настройках** и **Интересах** как захочешь.

Готово. Окно можно закрывать крестиком — программа свернётся в трей, не выключится.

## Вариант 2 — из исходного кода (для разработчиков)

Нужен Python 3.11+, Windows и [Ollama](https://ollama.com) (в готовой сборке .exe она уже встроена,
а при запуске из исходников — своя копия не собирается, поэтому ставится отдельно, как обычная
программа).

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m nexus panel
```

Дальше — то же самое, пункт 3 выше (скачать модель через Настройки).

## Если что-то не работает

- **Nexus не открывается (запуск из исходников)** — проверь, что Ollama установлена и запущена
  хотя бы раз вручную. Готовая сборка `.exe` в этом не нуждается — движок уже внутри.
- **Модель долго скачивается** — это нормально, несколько ГБ по сети. Прогресс не показывается,
  просто жди, кнопка станет активной снова.
- **Хочу свою «приоритетную программу»** (чтобы Nexus уступал ей видеокарту) — Настройки →
  «Приоритетная программа»: впиши название и либо имя процесса (.exe), либо порт, по которому её
  можно узнать. Пусто — функция выключена.
